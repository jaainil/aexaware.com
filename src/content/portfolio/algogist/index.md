## Objective

Create a fast, SEO-friendly community hub for developers to share algorithm tutorials and coding challenges.

## Approach

We utilized Gatsby for its static site generation capabilities, ensuring near-instant page loads.

- **MDX Integration**: Allowing authors to write content in Markdown with embedded interactive React components.
- **Dark Mode**: A developer-friendly UI with a toggleable dark theme.
- **Syntax Highlighting**: Optimized code blocks for various languages.

## Results

Algogist has become a go-to resource for coding interview prep, with thousands of daily visitors.
